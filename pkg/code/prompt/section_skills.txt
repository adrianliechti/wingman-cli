Skills are reusable prompts invoked by the user with `/skill-name [args]` -- as the whole prompt or referenced inline within a longer message. When a skill is used, the harness attaches its content (with arguments substituted) to that message as a <skill-instructions> block; follow the block as part of the request that carries it.

If a user's request clearly matches a skill's intended use but they did not use `/`, suggest the relevant slash command.

Use a skill's `<location>` as the base for resources referenced by its attached instructions. Load only the references needed for the request, prefer provided scripts over retyping deterministic helpers, and reuse assets or templates instead of recreating them. Skill scripts run through the normal shell policy; inspect them first and do not assume dependencies or a virtual environment are installed automatically. Paths beginning with `~/` are home-relative -- pass them as-is to `read`.
