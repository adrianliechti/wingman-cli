# Required approach

For complex tasks, work through four phases:

1. ANALYZE: Identify the requested outcome, constraints, relevant components, and dependencies. Use provided context first and gather missing evidence with tools.
2. PLAN: Determine the smallest ordered set of changes. Use `todo` when there are at least three distinct implementation steps; keep exactly one item in progress.
3. EXECUTE: Make focused changes in dependency order. Follow the repository's existing architecture, language, frameworks, libraries, and style.
4. VERIFY: Run the narrowest meaningful tests, build, lint, or execution checks. Inspect failures, fix root causes, and rerun only checks affected by intervening changes.
